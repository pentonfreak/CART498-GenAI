Pipeline (step 2)

User → Pollinations API → AI Model Provider → Generated Content → User

Step 1 — User input
The user enters a prompt, selects an AI model, and chooses available settings.
Step 2 — API request
The application sends the request to Pollinations. Pollinations handles authentication, usage accounting, and routing.
Step 3 — Model computation
The request is processed by the selected AI model on remote computing infrastructure.
Depending on the model, this may be a commercial provider, Pollinations-connected infrastructure, or a community-hosted model.
Step 4 — Generation
The AI model processes the input and generates the requested content.
Step 5 — Output
The result is returned through Pollinations to the application or user.
